# MyTasks Web

React frontend for the MyTasks task management application.

## Requirements

* Node.js
* npm
* MyTasks API running locally

## Installation

Clone the repository (if using console):

```bash
git clone <repository-url>
cd mytasks-web
```

Install dependencies:

```bash
npm install
```

## Run the Application

Make sure the MyTasks API is running first.

Then start the frontend:

```bash
npm run dev
```

Open the URL shown in the terminal, usually:

```text
http://localhost:5173
```

## API

The frontend communicates with the MyTasks API through `/api/tasks`.

The API is maintained in a separate repository and has its own setup instructions.

## Tech Stack

* React
* TypeScript
* Vite
* CSS Modules
